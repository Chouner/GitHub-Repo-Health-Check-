如何获取 GitHub Token？
1. 打开 GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 点击 Generate new token (classic)
3. Note 填写任意名称，勾选 public_repo 权限即可
4. 生成后复制 Token，粘贴到上方输入框保存

配置后额度从 60次/小时 提升至 5000次/小时

密钥仅保存在浏览器本地存储，不会上传至服务器
